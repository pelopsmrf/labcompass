# Кабинет ЛабКомпас (labcompass.ru/app/)

Платная часть платформы. Сейчас в ней один модуль — учёт оборудования: сроки поверки, калибровки
и аттестации, напоминания на почту, график в Excel, вставка списка из Excel, поверки из ФГИС «Аршин».
Бесплатный тариф — до `FREE_LIMIT` единиц, подписку включает админ (дата «оплачено до»).

| Файл | Что внутри |
|---|---|
| `main.py` | адреса сайта: вход по коду, оборудование, импорт, Excel, профиль, админка |
| `equipment.py` | расчёт сроков и статусов, разбор вставки из Excel, выгрузка графика |
| `arshin.py` | поиск поверок в открытом API ФГИС «Аршин»: в карточке (выбор записи) и обновление всех СИ |
| `db.py` | настройки из `.env` и схема базы SQLite |
| `mailer.py` | отправка писем через SMTP |
| `remind.py` | ежедневные напоминания (за 30 и 7 дней и в день срока) |
| `templates/`, `static/` | страницы (Jinja2) и оформление |
| `deploy/` | systemd-службы, таймер напоминаний, Caddyfile, резервное копирование |

## Запуск на своём компьютере

```bash
python3 -m venv .venv && .venv/bin/pip install -r requirements.txt
cp .env.example .env      # в .env: SMTP_HOST= (пусто — код входа пишется в консоль), COOKIE_SECURE=0
.venv/bin/uvicorn main:app --reload --port 8000
```
Открыть http://127.0.0.1:8000/app/

## ФГИС «Аршин»
- Ищем по точному заводскому № и № в госреестре СИ (25405-03). Без № госреестра — все приборы с таким
  номером, пользователь выбирает свой в карточке.
- Массовое обновление: не чаще раза в 5 минут на кабинет, пауза 1 с между запросами.
- API «Аршина» открывается с ВМ (cloud.ru); с зарубежных серверов — нет. Тесты идут без сети (подменная функция).

## Тесты
```bash
.venv/bin/pip install httpx && .venv/bin/python -m unittest test_app
```

## Безопасность
- Пароли не хранятся: вход по одноразовому коду (6 цифр, 10 минут, 5 попыток, не чаще раза в минуту).
- В базе лежат только хэши кодов и сессий. Cookie: HttpOnly, Secure, SameSite=Lax.
- POST-запросы с чужих сайтов отклоняются (проверка Origin).
- Админка: флаг администратора (почты из `ADMIN_EMAILS`) + отдельный пароль Caddy на `/app/admin`.
