# Сайт labcompass.ru

Статический лендинг ЛабКомпас + калькулятор ЛабКомпас.ВЛК по адресу /vlk/.

## Как обновить
1. Контакты: `config.json` (`email`, `telegram` — ник без @; пустой ник скрывает кнопку Telegram).
2. Тексты: `src/index.html`, оформление: `src/style.css`.
3. Сборка: `node build.js` → готовый сайт в `dist/` (заодно пересобирается калькулятор из `../vlk_web`).

## Как выложить
Загрузите **содержимое** папки `dist/` в корень сайта на хостинге (`index.html` должен лежать в корне),
затем в панели регистратора домена укажите DNS-серверы хостинга. Подойдёт любой хостинг
статических файлов; база данных и PHP не нужны.

Сайт не собирает персональные данные (нет форм и счётчиков). Если добавите Яндекс Метрику
или форму заявки — понадобятся политика обработки персональных данных и уведомление о cookie.
