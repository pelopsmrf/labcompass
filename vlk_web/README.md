# ЛабКомпас.ВЛК: веб-версия калькулятора ВЛК

Одна HTML-страница: оперативный контроль и контрольные карты Шухарта по РМГ 76-2014.
Все расчёты выполняются в браузере, данные никуда не отправляются.

## Как пользоваться
Откройте `dist/labcompass-vlk.html` двойным щелчком (Chrome, Edge, Firefox, Яндекс Браузер), без интернета и установки.

1. Введите параметры методики: σr, σRл, Δ (или сразу Δл лаборатории).
2. Скопируйте результаты из Excel и вставьте (Ctrl+V) в таблицу. Порядок столбцов: дата, вид, X₁, X₂, C, X′₁, X′₂.
   Можно также импортировать CSV, в том числе файлы от `vlk_calc/vlk.py`.
3. Итоги и контрольные карты обновляются сразу. «Печать / сохранить в PDF» даёт готовый отчёт.

Данные автоматически сохраняются в браузере. Для разных показателей используйте «Сохранить проект» и «Открыть проект» (файл `.vlk.json`).

## Разработка
- `src/vlk-core.js`: расчёты (тот же алгоритм, что в `vlk_calc/vlk.py`); `src/app.js`: интерфейс.
- `node build.js`: собирает всё в один файл `dist/labcompass-vlk.html`.
- `node --test test/core.test.js`: тесты, включая построчную сверку с Python-версией на `vlk_calc/example.csv`.
