# ЛабКомпас.ВЛК: калькулятор ВЛК (РМГ 76-2014)

Проверяет результаты внутрилабораторного контроля, строит контрольные карты Шухарта,
ищет признаки нарушения стабильности и формирует HTML-отчёт.

## Запуск

```bash
python3 vlk.py example.csv --name "Аммоний-ион" --units "мг/дм³" \
    --sigma-r 4 --sigma-R 6 --delta 15
```

Параметры (в процентах, относительные):

| Параметр | Что это |
|---|---|
| `--sigma-r` | σr, показатель повторяемости |
| `--sigma-R` | σRл, показатель внутрилабораторной прецизионности |
| `--delta` | Δ из методики; тогда Δл = 0,84·Δ |
| `--delta-lab` | Δл лаборатории, если уже установлен (вместо `--delta`) |
| `-o` | имя HTML-отчёта (по умолчанию рядом с CSV) |

Нужны Python 3.8+ и matplotlib (`pip install matplotlib`).

## Формат входного файла

CSV из Excel («Сохранить как → CSV (разделители — точка с запятой)»). Десятичная запятая допускается.

| Колонка | Значение |
|---|---|
| `дата` | дата контроля |
| `вид` | `повт`, `прец`, `ок` или `доб` |
| `x1`, `x2` | параллельные определения (для `прец` — результаты в разных условиях) |
| `c` | аттестованное значение ОК (`ок`) или величина добавки (`доб`) |
| `xd1`, `xd2` | результаты по пробе с добавкой (`доб`) |

Пример: `example.csv`.

## Что проверяется

- Повторяемость: |X₁ − X₂| ≤ 2,77·σr
- Внутрилабораторная прецизионность: |X₁ − X₂| ≤ 2,77·σRл
- Точность по ОК: |X̄ − C| ≤ Δл
- Точность методом добавок: |X̄′ − X̄ − C| ≤ √(Δл,X̄′² + Δл,X̄²)
- Контрольные карты (при 3 и более точках): выход за предел действия; 2 из 3 точек за пределом
  предупреждения; 9 точек подряд по одну сторону средней линии; 6 точек подряд монотонно.

Коэффициенты собраны в начале `vlk.py`. Перед применением в лаборатории сверьте их
с действующей редакцией РМГ 76-2014 и процедурой ВЛК лаборатории.
